# 11:11 — A Universe Made for Zainab

A responsive, single-page romantic website made with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the project folder.
2. Open it in VS Code.
3. Open `index.html` in your browser, or use the VS Code **Live Server** extension and click **Go Live**.

No build step or package installation is required.

## Personalize it
Open `content.js`:
- Change the 11 reasons and messages.
- Replace the photo paths/captions.
- Add your M4A audio path under `musicPath`.

## Add your photos
Put your chosen images in the `assets` folder and name them:
- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`

Or change the paths in `content.js` to match your filenames.

## Add music
Place an M4A audio file in `assets/our-song.m4a`. The player is user-activated and does not autoplay.

## Publish
You can publish this static site with GitHub Pages or Vercel. Upload the contents of this folder to a repository and configure the host to serve the project root. No server or environment variables are needed.
